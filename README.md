Prompt for Lovable

Project Title

SkillBridge – Student Skill Exchange Platform

Project Objective

Create a modern web application called SkillBridge, a platform where students can exchange skills instead of paying for courses. Students can teach the skills they already know and learn new skills from other students through peer-to-peer collaboration.

The website should have a clean, professional, responsive design suitable for a final-year engineering project with a modern UI and good user experience.
